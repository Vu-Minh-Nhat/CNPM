## Quy ước

- Nội dung phải thống nhất với đề tài và task Jira.
- Mã FR, NFR, UC và BR được giữ ổn định.
- Phân biệt yêu cầu dự kiến với kết quả đã triển khai.
- Kết quả kiểm thử cần ghi rõ phiên bản và môi trường.
- Không lưu mật khẩu, token hoặc thông tin kết nối bí mật.
